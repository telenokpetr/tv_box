# Личная версия для Android TV

Изменена отдельная копия проекта. Исходная папка Downloads не менялась.

Оформление: однотонный графитовый фон, голубой акцент, крупная типографика,
основные кнопки высотой 64, боковое меню шириной 176 с подписями.
Начальный масштаб текста — 115%, карточек — 130%.
Если настройки уже сохранены, установите эти значения вручную в настройках.

Стрелки перемещают фокус. OK активирует элемент. Назад использует существующую
обработку Android. Карточки получают контрастную рамку и прокручиваются к фокусу.
На широком экране Android отключён компактный телефонный вид карточек.
Добавлены TV launcher, баннер и необязательное требование сенсорного экрана.
Оформление также меняется в настольной версии.

Основные изменения находятся в lib/shared/theme, lib/shared/navigation,
lib/shared/keyboard/remote_shortcuts.dart, lib/shared/widgets/media_poster_card.dart,
lib/shared/utils/poster_grid_delegate.dart, lib/app.dart и настройках масштаба
в lib/features/settings/providers/settings_provider.dart.

Проверена компиляция lib/main.dart во Flutter kernel с Flutter 3.47.5.
Отдельная сцена с настоящими компонентами меню проверена в Flutter Engine:
OK активирует первый пункт, стрелка вниз переносит фокус, OK активирует второй.
Стандартный flutter test не запустился из-за ограничений среды на дочерние процессы.
APK не собрана. Физический Android TV и все экраны приложения пока не проверены.
Перетаскивание на досках требует отдельной адаптации под управление пультом.

Для локальной проверки нужны Flutter и Android SDK:

```powershell
flutter pub get
flutter test test/shared/keyboard/remote_navigation_test.dart
flutter build apk --debug
```

APK: build/app/outputs/flutter-apk/app-debug.apk.
Для release-сборки проект требует собственного ключа подписи.
